Introducción a la Infraestructura como Código

Qué problema resuelve Terraform, qué es la IaC y cómo encaja Terraform frente a otras herramientas.

🎯 Objetivos de aprendizaje

Al terminar este módulo serás capaz de:

  • Explicar qué es la Infraestructura como Código (IaC) y qué problemas resuelve.
  • Diferenciar el enfoque declarativo del imperativo.
  • Situar Terraform frente a Ansible, CloudFormation, Pulumi y OpenTofu.
  • Entender el ciclo de vida básico: escribir → planificar → aplicar → destruir.

📚 Contenido

  1. El problema de la infraestructura manual: «ClickOps», errores humanos, entornos que no se parecen entre sí, falta de historial.
  2. Qué es la IaC: la infraestructura descrita en archivos de texto, versionada en Git y revisable como cualquier código.
  3. Declarativo (describes el estado final) vs imperativo (describes los pasos). Idempotencia.
  4. Herramientas de aprovisionamiento (Terraform, CloudFormation, Pulumi) vs gestión de configuración (Ansible, Chef, Puppet).
  5. Terraform y OpenTofu: cambio de licencia (BSL, 2023), el fork OpenTofu y por qué lo aprendido sirve para ambos.
  6. Arquitectura de Terraform: el binario (core) + providers (plugins) + estado (state).
  7. Qué es HCL y qué es el Terraform Registry.
  8. Casos de uso reales: cloud (AWS, Azure, GCP), Kubernetes, GitHub, DNS, monitorización, SaaS…
✍️ Lección en desarrollo. Este es el guion del módulo. Ve sustituyendo este aviso por la explicación completa de cada punto.

🛠 Práctica guiada: Mapa mental de la IaC

  1. Elige una infraestructura sencilla que conozcas (por ejemplo, una web con un servidor y una base de datos).
  2. Escribe los pasos manuales que harías en la consola web para crearla.
  3. Reescribe lo mismo como una lista de «cosas que deben existir» (enfoque declarativo).
  4. Anota qué pasaría si tuvieras que repetirlo en 3 entornos (dev, staging, prod).

⚠️ Errores frecuentes

Pensar que Terraform sirve para instalar software dentro de servidores
Terraform crea y gestiona recursos; la configuración interna suele hacerla otra herramienta (cloud-init, Ansible, imágenes).
Creer que hay que aprender un lenguaje de programación
HCL es un lenguaje de configuración sencillo; no necesitas saber programar.
