Módulo 12

Importar y refactorizar

Traer infraestructura existente a Terraform y reorganizar el código sin destruir nada.

Intermedio⏱ 1,5 h

🎯 Objetivos de aprendizaje

Al terminar este módulo serás capaz de:

  • Importar recursos creados a mano con el bloque import.
  • Generar código automáticamente con -generate-config-out.
  • Renombrar y mover recursos con moved y dejar de gestionarlos con removed.

📚 Contenido

  1. Escenario real: infraestructura creada con la consola (ClickOps).
  2. Bloque import (Terraform 1.5+) vs el comando clásico terraform import.
  3. terraform plan -generate-config-out=generado.tf y cómo limpiar el código generado.
  4. Bloque moved para renombrar recursos o moverlos a módulos sin recrearlos.
  5. Bloque removed (1.7+) para soltar recursos del estado de forma declarativa.
  6. Herramientas externas: Terraformer, former2 (con espíritu crítico).
✍️ Lección en desarrollo. Este es el guion del módulo. Ve sustituyendo este aviso por la explicación completa de cada punto.

🧩 Ejemplo

🛠 Práctica guiada: Rescata un recurso hecho a mano

  1. Crea un bucket y un security group desde la consola web.
  2. Escribe los bloques import y ejecuta terraform plan -generate-config-out=generado.tf.
  3. Limpia el código generado y aplica hasta que el plan diga «No changes».
  4. Mueve el recurso a un módulo usando un bloque moved.
💸 Recuerda: si has creado recursos en la nube, ejecuta terraform destroy al terminar.

⚠️ Errores frecuentes

El plan quiere modificar el recurso importado
Tu código no coincide con la realidad. Ajusta argumentos hasta que no haya cambios.
ID de importación incorrecto
Cada recurso usa un formato distinto: consulta la sección «Import» en la doc del provider.
