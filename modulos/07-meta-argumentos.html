Módulo 07

Meta-argumentos: count, for_each y lifecycle

Crear múltiples recursos y controlar su ciclo de vida.

Intermedio⏱ 2 h
En esta página ObjetivosContenidoEjemploPrácticaComandosErrores frecuentesAutoevaluación

🎯 Objetivos de aprendizaje

Al terminar este módulo serás capaz de:

  • Crear N recursos con count y con for_each, y elegir entre ellos.
  • Controlar el ciclo de vida con lifecycle.
  • Proteger recursos críticos contra borrados accidentales.

📚 Contenido

  1. Meta-argumentos disponibles en todo recurso: count, for_each, depends_on, provider, lifecycle.
  2. count + count.index; creación condicional con count = var.crear ? 1 : 0.
  3. for_each con map o set: each.key, each.value.
  4. Por qué for_each suele ser mejor: eliminar un elemento de en medio con count desplaza índices y recrea recursos.
  5. lifecycle: create_before_destroy, prevent_destroy, ignore_changes, replace_triggered_by.
  6. Forzar un reemplazo: terraform apply -replace=DIRECCION (sustituye al antiguo taint).
✍️ Lección en desarrollo. Este es el guion del módulo. Ve sustituyendo este aviso por la explicación completa de cada punto.

🧩 Ejemplo

🛠 Práctica guiada: count vs for_each

  1. Crea 3 archivos locales con count a partir de una lista.
  2. Elimina el elemento del medio y observa el plan.
  3. Repite con for_each y compara.
  4. Añade prevent_destroy a un recurso e intenta destruirlo.
💸 Recuerda: si has creado recursos en la nube, ejecuta terraform destroy al terminar.

⌨️ Comandos clave

ComandoQué haceCopiar
terraform apply -replace="aws_instance.web"Fuerza la recreación de un recurso.
terraform state list 'aws_iam_user.equipo'Lista las instancias de un recurso con for_each.
terraform plan -target='aws_iam_user.equipo["ana"]'Planifica solo un recurso (uso excepcional).

⚠️ Errores frecuentes

The "for_each" value depends on resource attributes that cannot be determined until apply
Las claves de for_each deben conocerse en el plan; usa valores estáticos o variables.
Abusar de -target
Es para emergencias; deja el estado desalineado con el código si se usa como rutina.
