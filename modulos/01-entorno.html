Módulo 01

Preparación del entorno

Terminal, instalación de Terraform, editor, Git y la cuenta en la nube preparada de forma segura.

Básico⏱ 1,5 h

🎯 Objetivos de aprendizaje

Al terminar este módulo serás capaz de:

  • Moverse con soltura por la terminal (Linux/macOS y PowerShell).
  • Instalar Terraform y gestionar varias versiones.
  • Configurar VS Code con la extensión oficial de HashiCorp.
  • Preparar Git y un repositorio para los ejercicios.
  • Crear una cuenta en AWS con un usuario no-root, MFA y alertas de presupuesto.

📚 Contenido

  1. Terminal mínima: pwd, ls, cd, mkdir, cat, rutas relativas/absolutas, variables de entorno.
  2. Instalar Terraform: gestor de paquetes (brew, apt, winget/choco) o binario manual; añadirlo al PATH.
  3. Gestores de versiones: tfenv o tenv y el archivo .terraform-version.
  4. VS Code + extensión «HashiCorp Terraform»: resaltado, autocompletado, formateo al guardar.
  5. Git básico y un .gitignore correcto para Terraform (qué nunca se sube).
  6. Cuenta AWS segura: MFA en root, usuario IAM/IAM Identity Center, AWS CLI y perfiles.
  7. Control de costes: capa gratuita, AWS Budgets, y la regla de oro «terraform destroy al terminar».
  8. Alternativa sin coste: Docker Desktop / provider local para los primeros módulos.
✍️ Lección en desarrollo. Este es el guion del módulo. Ve sustituyendo este aviso por la explicación completa de cada punto.

🧩 Ejemplo

🛠 Práctica guiada: Entorno listo

  1. Instala Terraform y comprueba la versión con terraform version.
  2. Activa el autocompletado: terraform -install-autocomplete.
  3. Instala la AWS CLI y ejecuta aws configure (o aws configure sso).
  4. Verifica la identidad con aws sts get-caller-identity.
  5. Crea un presupuesto de 5 USD con alerta por email en AWS Budgets.
  6. Crea un repositorio terraform-labs con el .gitignore anterior.

⌨️ Comandos clave

ComandoQué haceCopiar
terraform versionMuestra la versión de Terraform y de los providers.
terraform -install-autocompleteInstala el autocompletado en bash/zsh.
aws sts get-caller-identityComprueba con qué cuenta y usuario estás autenticado.
tfenv install 1.9.8 && tfenv use 1.9.8Instala y activa una versión concreta (ejemplo).

⚠️ Errores frecuentes

terraform: command not found
El binario no está en el PATH. Reabre la terminal o añade la carpeta al PATH.
Usar la cuenta root de AWS con access keys
Nunca. Crea un usuario/rol con permisos y activa MFA en root.
Subir terraform.tfstate o claves a GitHub
Configura el .gitignore antes del primer commit y usa git status antes de cada git add.
