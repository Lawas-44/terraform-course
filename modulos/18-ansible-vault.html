Módulo 18

Ansible Vault y buenas prácticas

Guardar contraseñas cifradas y mantener el código de Ansible limpio con ansible-lint.

Objetivos

Al terminar este módulo sabrás:

  • Cifrar y descifrar archivos con Ansible Vault.
  • Usar variables cifradas en un playbook.
  • Configurar Ansible con ansible.cfg.
  • Revisar el código con ansible-lint.

Lección

El problema de las contraseñas

Tarde o temprano necesitarás una contraseña en tu código: la de una base de datos, la de una zona privada... Si la escribes tal cual en un archivo YAML y lo subes a Git, cualquiera con acceso al repositorio la verá.

Ansible Vault cifra archivos con una contraseña. El archivo cifrado sí se puede subir a Git: sin la contraseña del vault no se puede leer.

Revisar el código: ansible-lint

ansible-lint revisa tus playbooks y roles y avisa de errores y malas prácticas: nombres de módulos incompletos, permisos de archivo sin indicar, comandos que deberían ser módulos...

Buenas prácticas

  • Pon un name claro a cada tarea.
  • Usa el nombre completo de los módulos (ansible.builtin.apt).
  • Indica siempre mode al crear archivos y carpetas.
  • Usa módulos en lugar de command o shell. Si usas command, añade changed_when.
  • Ejecuta los playbooks dos veces: la segunda debe salir changed=0.
  • Prueba primero con --check --diff.
  • Cifra los secretos con Vault y marca sus tareas con no_log: true.

Práctica guiada

Un secreto cifrado (carpeta labs/18-ansible-vault)

  1. Cifra el archivo secretos.yml con ansible-vault encrypt.
  2. Ábrelo con cat y comprueba que no se puede leer.
  3. Ejecuta el playbook con --ask-vault-pass.
  4. Pasa ansible-lint y corrige los avisos.
ImportanteSi has creado recursos en la nube, ejecuta terraform destroy al terminar para no pagar por ellos.

Comandos clave

ComandoQué haceCopiar
ansible-vault create secretos.ymlCrea un archivo cifrado.
ansible-vault encrypt secretos.ymlCifra un archivo existente.
ansible-vault edit secretos.ymlEdita un archivo cifrado.
ansible-vault view secretos.ymlMuestra el contenido descifrado.
ansible-playbook site.yml --ask-vault-passPide la contraseña del vault al ejecutar.
ansible-lintRevisa el código y avisa de malas prácticas.

Errores frecuentes

Attempting to decrypt but no vault secrets found
El playbook usa un archivo cifrado. Añade --ask-vault-pass.
Subir la contraseña del vault a Git
La contraseña del vault nunca se sube. Guárdala en un gestor de contraseñas o en los secretos del CI.
