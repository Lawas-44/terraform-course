Qué es un provider

Terraform Core no sabe nada de AWS, Azure ni GitHub. Todo ese conocimiento vive en los providers: plugins que traducen tus bloques resource a llamadas a la API correspondiente. Hay más de 4.000 en el Terraform Registry (registry.terraform.io), clasificados en tres niveles:

NivelQuién lo mantieneEjemplos
OfficialHashiCorpaws, azurerm, google, kubernetes, random, local
PartnerLa empresa del serviciocloudflare, datadog, mongodbatlas
CommunityPersonas de la comunidadMuchos útiles; revisa su mantenimiento

La documentación de cada provider en el Registry es la referencia que más vas a consultar. Para cada recurso encontrarás un ejemplo, los argumentos (Argument Reference), los atributos que exporta (Attribute Reference) y cómo importarlo (Import).

Declarar providers y versiones

Los providers se declaran en required_providers con una dirección (source) y una restricción de versión:

RestricciónSignificadoAcepta
= 6.2.0Exactamente esa6.2.0
>= 6.0Esa o superior6.0, 6.5, 7.0, 8.1…
~> 6.0Solo cambia el último número indicado6.0 … 6.99 (no 7.0)
~> 6.2.0Solo parches6.2.0 … 6.2.x
>= 6.0, < 7.0Rango explícitoigual que ~> 6.0
💡 Consejo. En proyectos usa ~> MAYOR.MENOR para recibir mejoras sin cambios incompatibles. Las versiones mayores (6 → 7) suelen romper cosas y conviene actualizarlas a propósito.

Autenticación: nunca claves en el código

El provider de AWS busca credenciales en este orden, igual que la AWS CLI:

  1. Argumentos del bloque provider (access_key, secret_key) — no los uses nunca.
  2. Variables de entorno: AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_SESSION_TOKEN.
  3. Perfil de ~/.aws/config y ~/.aws/credentials (el indicado en AWS_PROFILE o profile).
  4. Rol de la máquina o contenedor (EC2 instance profile, ECS, OIDC en CI…).
⚠️ Cuidado. Si escribes access_key = "AKIA..." en un .tf y lo subes a GitHub, en minutos habrá bots usando tu cuenta para minar criptomonedas. No es una exageración.

S3 es el almacenamiento de objetos de AWS. Un bucket es gratuito mientras esté vacío (y casi gratuito con pocos datos). Crea una carpeta nueva con estos archivos:

ℹ️ Nota. En el provider AWS moderno, la configuración del bucket (versionado, cifrado, políticas, web…) se hace con recursos separados como aws_s3_bucket_versioning, no con bloques dentro de aws_s3_bucket. Lo verás en tutoriales antiguos de la otra forma.

Abre la consola de AWS → S3 y busca tu bucket. Mira la pestaña Properties: verás el versionado activado y las etiquetas de default_tags. Cuando termines: terraform destroy.

ℹ️ Nota. Novedad del provider AWS 6.x: muchos recursos aceptan directamente un argumento region = "us-east-1", así que para el caso «misma cuenta, otra región» ya no siempre hace falta un alias. Para otra cuenta (assume_role) los alias siguen siendo necesarios.

🛠 Práctica guiada: Tu primer bucket S3

  1. Configura un perfil con aws configure --profile curso-terraform.
  2. Crea el bucket del ejemplo y localízalo en la consola de AWS.
  3. Revisa el contenido de .terraform.lock.hcl.
  4. Cambia la restricción de versión y prueba terraform init -upgrade.
  5. Destruye el bucket.
💸 Recuerda: si has creado recursos en la nube, ejecuta terraform destroy al terminar.

⚠️ Errores frecuentes

No valid credential sources found
No hay credenciales. Revisa AWS_PROFILE y aws sts get-caller-identity.
BucketAlreadyExists
Los nombres de bucket son globales. Usa bucket_prefix o un sufijo aleatorio.

1¿Qué versiones acepta la restricción ~> 6.0?

~> permite que aumente solo el último número indicado (el menor, en este caso).

2¿Para qué sirve .terraform.lock.hcl?

Garantiza que todos instalan exactamente la misma versión. Se sube a Git.

3¿Cuál es la forma CORRECTA de dar credenciales de AWS a Terraform?

Las credenciales deben vivir fuera del código: perfiles, SSO, variables de entorno o roles.

4Has cambiado version = "~> 5.0" por "~> 6.0". terraform init falla. ¿Qué haces?

El lock file aún apunta a la 5.x; -upgrade permite elegir una versión nueva.

5¿Por qué usamos bucket_prefix en lugar de bucket?

AWS genera un sufijo único para que no choque con buckets de otras personas.

6¿Cómo indicas que un recurso use el provider con alias = "virginia"?

El meta-argumento provider recibe NOMBRE.ALIAS sin comillas.
