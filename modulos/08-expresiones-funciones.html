Operaciones básicas

Elegir entre dos valores

Para elegir un valor según una condición se escribe condición ? si_es_verdad : si_es_falso:

Se lee así: «si es producción, usa t3.medium; si no, t3.micro».

ImportanteLos dos valores deben ser del mismo tipo. local.es_prod ? 3 : "uno" da error porque mezcla un número y un texto.

Práctica guiada

Juega en la consola

  1. En terraform console calcula 4 subredes /24 dentro de 10.0.0.0/16 con cidrsubnet.
  2. Convierte una lista de nombres en un mapa nombre → longitud.
  3. Genera un JSON de política IAM con jsonencode.
  4. Renderiza un user_data con templatefile.
ImportanteSi has creado recursos en la nube, ejecuta terraform destroy al terminar para no pagar por ellos.

Errores frecuentes

Inconsistent conditional result types
Las dos ramas del ternario deben devolver el mismo tipo.
dynamic en exceso
Si el código se vuelve ilegible, simplifica o separa en recursos independientes.

Test

Elige una respuesta en cada pregunta. Verás la explicación al momento. Con un 80 % o más, el módulo está superado.

01¿Qué devuelve [for n in ["a", "bb", "ccc"] : length(n)]?

Una lista con la longitud de cada string.

02¿Qué devuelve { for n in ["a", "bb"] : n => upper(n) }?

Con llaves y => se construye un map.

03¿Qué devuelve cidrsubnet("10.0.0.0/16", 8, 5)?

/16 + 8 bits = /24; la subred número 5 es 10.0.5.0/24.

04¿Por qué var.x ? 1 : "no" da error?

Ambas ramas deben ser del mismo tipo (o convertibles).

05¿Para qué sirve un bloque dynamic?

Genera bloques como ingress, setting… a partir de una colección.

06¿Cuál es la mejor forma de escribir una política IAM en Terraform?

jsonencode garantiza JSON válido y permite usar referencias y expresiones.

07¿Qué devuelve try(local.mapa.no_existe, "defecto")?

try devuelve la primera expresión que se evalúa sin error.

Responde todas las preguntas para ver tu nota.
