Módulo 04

Variables, outputs y locals

Parametrizar configuraciones, exponer resultados y evitar repetición.

Nivel: BásicoDuración: 2 hTest: 7 preguntasRetos: 2Proyecto: paso 5

Objetivos

Al terminar este módulo sabrás:

  • Declarar variables con tipo, descripción, valor por defecto y validación.
  • Conocer todas las formas de asignar valores y su orden de precedencia.
  • Exponer datos con outputs y consumirlos desde la terminal.
  • Usar locals para nombres y etiquetas comunes.
  • Marcar valores como sensitive y saber sus limitaciones.

Lección

Para qué sirven

Hasta ahora escribíamos los valores directamente en el código. Pero a menudo quieres usar el mismo código con datos distintos: un entorno de pruebas pequeño y uno de producción grande, un nombre u otro...

HerramientaQué esCómo se usa
variableUn dato de entrada que puedes cambiarvar.nombre
outputUn dato que se muestra al terminarbloque output
localsUn valor de ayuda calculado dentro del códigolocal.nombre

Crear una variable

Una variable se crea con un bloque variable. Lo recomendable es indicar su tipo y una descripción:

  • type: el tipo de dato (string es texto, number es número, bool es verdadero/falso).
  • default: el valor si nadie da otro. Si una variable no tiene default, es obligatoria.

Outputs: mostrar resultados

Los outputs muestran datos útiles al terminar, como una dirección web o un nombre:

Con -raw sale el valor sin comillas, útil para usarlo en otros comandos.

Locals: no repetir

Si escribes lo mismo muchas veces, guárdalo en un local. A diferencia de una variable, un local no se puede cambiar desde fuera: es un cálculo interno.

Valores secretos

Si una variable o un output contiene una contraseña, márcalo con sensitive = true. Así Terraform no la muestra en pantalla:

Importantesensitive solo oculta el valor en pantalla. El valor sigue guardado sin cifrar en el archivo de estado (terraform.tfstate). Por eso ese archivo nunca se comparte.

Práctica guiada

Parametriza el proyecto del módulo 2

  1. Convierte el nombre del archivo y el contenido en variables.
  2. Crea dev.tfvars y prod.tfvars y aplica con -var-file.
  3. Prueba a dar un valor no permitido y observa la validación.
  4. Exporta TF_VAR_proyecto=demo y comprueba la precedencia.
  5. Saca un output en JSON y fíltralo con jq.

Comandos clave

ComandoQué haceCopiar
terraform plan -var="entorno=prod"Asigna una variable desde la línea de comandos.
terraform apply -var-file="prod.tfvars"Carga variables desde un archivo.
export TF_VAR_proyecto=demoAsigna una variable vía entorno (bash).
$env:TF_VAR_proyecto = "demo"Lo mismo en PowerShell.
terraform output -json | jqOutputs en JSON formateado.
terraform output -raw prefijoValor sin comillas, ideal para scripts.

Errores frecuentes

Terraform pregunta por una variable cada vez
No tiene default ni valor asignado. Añádelo a terraform.tfvars.
Creer que sensitive cifra el valor
Solo lo oculta en la salida. Protege el estado (backend cifrado, acceso restringido).
