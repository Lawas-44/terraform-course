Introducción a Ansible

Qué es Ansible, cómo se conecta a los servidores, el inventario y los primeros comandos.

Nivel: BásicoDuración: 1,5 hTest: 6 preguntasRetos: 2Proyecto: paso 13

Objetivos

Al terminar este módulo sabrás:

  • Explicar qué hace Ansible y en qué se diferencia de Terraform.
  • Instalar Ansible y comprobar que funciona.
  • Escribir un inventario con tus servidores.
  • Ejecutar comandos en varios servidores a la vez.

Lección

Qué es Ansible

Con Terraform ya sabes crear servidores. Pero un servidor recién creado está vacío: no tiene tu web, ni nginx, ni nada configurado. Ansible se encarga de eso: entra en los servidores y los configura (instala programas, copia archivos, arranca servicios...).

TerraformAnsible
Para quéCrear infraestructura: redes, servidores, firewallsConfigurar lo que hay dentro de los servidores
Cómo trabajaHabla con la API de la nubeEntra en los servidores por SSH
LenguajeHCL (archivos .tf)YAML (archivos .yml)
Recuerda lo que hizoSí, en el estadoNo: cada vez mira cómo está el servidor

Por eso se usan juntos: Terraform crea los servidores y Ansible los configura.

Cómo funciona

  • Ansible se instala solo en tu ordenador (el nodo de control). En los servidores no hay que instalar nada.
  • Se conecta a cada servidor por SSH, igual que harías tú a mano.
  • En los servidores solo necesita que haya Python, que ya viene en casi todos los Linux.

Instalar Ansible

Ansible funciona en Linux y macOS. En Windows se usa dentro de WSL (lo instalaste en el módulo 1).

El inventario: la lista de servidores

Ansible necesita saber a qué servidores conectarse. Esa lista se llama inventario y es un archivo de texto. Los servidores se agrupan con un nombre entre corchetes:

  • [web] es un grupo. Puedes tener varios: [web], [basedatos]...
  • web1 es el nombre que tú le das; ansible_host es su IP.
  • [web:vars] define variables para todo el grupo. ansible_user es el usuario con el que entra por SSH (en Ubuntu de AWS es ubuntu).
  • Existe siempre el grupo especial all, que incluye a todos los servidores.

El archivo ansible.cfg

Para no repetir opciones en cada comando, se crea un archivo ansible.cfg en la carpeta del proyecto. Ansible lo lee solo:

Con esto ya no hace falta escribir -i inventario.ini. host_key_checking = False evita que Ansible pregunte si confías en cada servidor la primera vez (útil mientras aprendes).

Comandos ad-hoc

Un comando ad-hoc es una orden suelta que se ejecuta en varios servidores a la vez. Sirve para comprobaciones rápidas. La forma es: ansible GRUPO -m MÓDULO -a "OPCIONES".

El primero que siempre se prueba es ping. No es un ping de red: comprueba que Ansible puede entrar y usar Python:

Más ejemplos:

  • -a "uptime": ejecuta un comando de Linux.
  • -m apt: usa el módulo apt para instalar un paquete.
  • -b (become): ejecuta como administrador, como sudo.
NotaUn módulo es una acción ya preparada: instalar un paquete (apt), copiar un archivo (copy), arrancar un servicio (service)... Ansible trae cientos.

Práctica guiada

Primeros comandos con Ansible (carpeta labs/13-ansible-intro)

  1. Instala Ansible y ejecuta ansible --version.
  2. Ejecuta ansible local -m ping con el inventario del lab.
  3. Ejecuta ansible local -a "uptime" y ansible local -m setup -a "filter=ansible_distribution*".
  4. Añade al inventario un servidor de AWS (si tienes uno del módulo 6) y haz ping.
ImportanteSi has creado recursos en la nube, ejecuta terraform destroy al terminar para no pagar por ellos.

Comandos clave

ComandoQué haceCopiar
ansible --versionMuestra la versión de Ansible.
ansible all -m pingComprueba que Ansible llega a todos los servidores.
ansible web -a "uptime"Ejecuta un comando en el grupo web.
ansible web -b -m apt -a "name=htop state=present"Instala un paquete con permisos de administrador.
ansible-inventory --graphMuestra los grupos y servidores del inventario.

Errores frecuentes

UNREACHABLE! ... Permission denied (publickey)
Ansible no puede entrar por SSH. Revisa el usuario (ansible_user) y que tu clave SSH es la correcta.
Host key verification failed
Es la primera vez que te conectas a ese servidor. Entra una vez con ssh o pon host_key_checking = False en ansible.cfg mientras aprendes.
Ansible no funciona en Windows
Ansible necesita Linux o macOS para ejecutarse. En Windows, úsalo dentro de WSL.
