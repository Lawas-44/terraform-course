Temario / Módulo 15

Variables, facts y plantillas

Personalizar la configuración con variables, datos de cada servidor y plantillas Jinja2.

Nivel: BásicoDuración: 2 hTest: 7 preguntasRetos: 2Proyecto: paso 15

Objetivos

Al terminar este módulo sabrás:

  • Definir variables en el playbook, en group_vars y en la línea de comandos.
  • Usar los facts: datos que Ansible recoge de cada servidor.
  • Generar archivos con plantillas Jinja2.
  • Recorrer listas dentro de una plantilla.

Lección

Variables

Como en Terraform, las variables sirven para no escribir los datos dentro de las tareas. Se usan escribiendo su nombre entre dobles llaves: {{ nombre }}.

ImportanteSi un valor empieza por {{, ponlo entre comillas: path: "{{ carpeta }}". Si no, YAML da error.

Dónde poner las variables

Lo más ordenado es guardarlas en la carpeta group_vars, junto al inventario. Ansible las carga solas según el grupo:

También puedes dar una variable al ejecutar. Esta forma gana a todas las demás:

DóndePrioridad
defaults/ de un rol (módulo 17)La más baja
group_vars/all.ymlBaja
group_vars/GRUPO.ymlMedia
vars: en el playbookAlta
-e al ejecutarLa más alta

Facts: lo que Ansible sabe de cada servidor

Al empezar un playbook, Ansible recoge información de cada servidor: nombre, sistema operativo, IP, memoria... Son los facts (hechos). Es la tarea Gathering Facts que ves al principio.

Se usan con ansible_facts['nombre'] (sin el prefijo ansible_):

FactEjemplo
ansible_facts['hostname']ip-10-0-1-25
ansible_facts['distribution']Ubuntu
ansible_facts['distribution_version']24.04
ansible_facts['default_ipv4']['address']10.0.1.25
ansible_facts['memtotal_mb']957

Y hay variables especiales que siempre existen, como inventory_hostname: el nombre del servidor en el inventario (web1, web2).

Bucles y condiciones en las plantillas

Jinja2 permite recorrer listas con {% for %} y elegir con {% if %}:

  • {{ }} muestra un valor.
  • {% %} es lógica: bucles y condiciones.
  • | aplica un filtro: | length (cuántos hay), | upper (mayúsculas), | default('nada') (valor si no existe).

Práctica guiada

Una página generada con plantilla (carpeta labs/15-ansible-plantillas)

  1. Revisa group_vars/all.yml y la plantilla pagina.html.j2.
  2. Ejecuta el playbook y abre el archivo generado.
  3. Cambia una variable y vuelve a ejecutarlo: solo cambia la plantilla.
  4. Pasa una variable con -e y comprueba que tiene prioridad.
ImportanteSi has creado recursos en la nube, ejecuta terraform destroy al terminar para no pagar por ellos.

Comandos clave

ComandoQué haceCopiar
ansible web -m setupMuestra todos los facts de los servidores.
ansible web -m setup -a "filter=ansible_distribution*"Muestra solo algunos facts.
ansible-playbook site.yml -e "web_nombre=Ana"Da valor a una variable al ejecutar.
ansible-inventory --host web1Muestra las variables de un servidor.

Errores frecuentes

'web_nombre' is undefined
La variable no existe. Revisa el nombre y que el archivo de group_vars está en la carpeta correcta.
Poner {{ }} al principio de un valor sin comillas
En YAML, si un valor empieza por {{, escríbelo entre comillas: dest: "{{ ruta }}".

Test

Elige una respuesta en cada pregunta. Verás la explicación al momento. Con un 80 % o más, el módulo está superado.

01¿Cómo se usa la variable carpeta dentro de una tarea?

Ansible usa la sintaxis de Jinja2: dobles llaves.

02¿Por qué hay que escribir path: "{{ carpeta }}" con comillas?

YAML interpreta { como el inicio de un diccionario.

03¿Dónde pondrías variables comunes a todos los servidores?

group_vars/all.yml se aplica a todos los servidores.

04¿Qué son los facts?

Nombre, sistema, IP, memoria... se recogen al empezar el playbook.

05¿Qué variable tiene el nombre del servidor en el inventario?

ansible_host es la IP; inventory_hostname es el nombre (web1, web2).

06¿Para qué sirve {% for %} en una plantilla?

Repite una parte de la plantilla por cada elemento.

07Tienes web_nombre en group_vars y ejecutas con -e web_nombre=Luis. ¿Qué valor se usa?

Las variables con -e tienen la prioridad más alta.

Responde todas las preguntas para ver tu nota.
