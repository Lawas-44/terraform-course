Handlers, condiciones y bucles

Reiniciar servicios solo cuando hace falta, repetir tareas y ejecutarlas solo si se cumple algo.

Objetivos

Al terminar este módulo sabrás:

  • Usar handlers para recargar un servicio solo si cambió su configuración.
  • Repetir una tarea con loop.
  • Ejecutar una tarea solo si se cumple una condición con when.
  • Guardar el resultado de una tarea con register.

Lección

Handlers: reiniciar solo cuando hace falta

Cuando cambias el archivo de configuración de un programa (por ejemplo, nginx), hay que recargarlo para que lea los cambios. Pero si la configuración no ha cambiado, recargarlo es innecesario.

Para eso están los handlers: tareas especiales que solo se ejecutan si otra tarea les avisa con notify y además esa tarea ha cambiado algo.

  • Si la plantilla cambia el archivo, la tarea sale changed y avisa al handler.
  • Si el archivo ya estaba igual, la tarea sale ok y el handler no se ejecuta.
  • Los handlers se ejecutan al final del playbook, y una sola vez aunque varias tareas les avisen.
ImportanteEl texto de notify debe ser exactamente igual al name del handler, incluidas mayúsculas.

Guardar resultados: register

register guarda el resultado de una tarea en una variable para usarlo después:

  • changed_when: false le dice a Ansible que esa tarea nunca cambia nada (solo consulta). Así no aparece como changed.
  • El módulo debug muestra un mensaje en pantalla. Muy útil para aprender y para buscar errores.

Errores frecuentes

El handler no se ejecuta
Solo se ejecuta si la tarea que lo avisa (notify) ha cambiado algo, y el nombre debe coincidir exactamente.
Reiniciar un servicio en cada ejecución
Usa un handler en lugar de una tarea con state: restarted.

01¿Cuándo se ejecuta un handler?

Si la tarea sale ok (sin cambios), el handler no se ejecuta.

02Tres tareas avisan al mismo handler y las tres cambian algo. ¿Cuántas veces se ejecuta?

Los handlers se ejecutan una sola vez, al final.

03¿Cómo se llama el elemento actual dentro de un loop?

Ansible usa item.

04¿Qué hace when: ansible_facts['distribution'] == "Ubuntu"?
