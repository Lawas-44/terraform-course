Qué es un módulo

Un módulo es una carpeta con archivos .tf. ¡Ya has estado usando uno! La carpeta donde ejecutas Terraform es el root module. Cuando desde ella llamas a otra carpeta, esa otra es un child module.

Los módulos son a Terraform lo que las funciones a la programación:

FunciónMódulo
Parámetrosvariable
Cuerporesource, data, locals
Valor de retornooutput
Llamadabloque module

Sirven para no repetir código, encapsular buenas prácticas (un bucket que siempre está cifrado y sin acceso público) y dar a otros equipos piezas probadas.

Registro privadoapp.terraform.io/mi-org/static-site/aws + version
  • // separa el repositorio de la subcarpeta del módulo.
  • ?ref= fija una etiqueta, rama o commit de Git. Usa siempre etiquetas de versión (v1.2.0), no main.
  • Versiona tus módulos con SemVer: MAYOR (rompe compatibilidad), MENOR (añade funciones), PARCHE (arreglos).

Buenas prácticas al diseñar módulos

  • Una responsabilidad clara: «red», «web estática», «base de datos». No un módulo que lo hace todo.
  • No envuelvas un único recurso sin añadir valor: un módulo que solo crea un aws_s3_bucket con los mismos argumentos no aporta nada.
  • No configures providers dentro de un módulo reutilizable: deja que los herede del root (o pásaselos con providers = { aws = aws.virginia }).
  • Todas las variables con description y type; valores por defecto sensatos y seguros.
  • Outputs para todo lo que otro pueda necesitar (IDs, ARNs, URLs).
  • Un README.md y una carpeta examples/ con un uso mínimo.
  • Genera la documentación automáticamente con terraform-docs:

🛠 Práctica guiada: Módulo de web estática

  1. Crea modules/static-site con un bucket S3 configurado como web.
  2. Expón el nombre del bucket y la URL como outputs.
  3. Instáncialo dos veces (dev y prod) con for_each.
  4. Sustituye tu VPC manual por el módulo oficial del Registry.
  5. Genera el README del módulo con terraform-docs markdown table.
💸 Recuerda: si has creado recursos en la nube, ejecuta terraform destroy al terminar.

⚠️ Errores frecuentes

Module not installed
Has añadido un módulo nuevo: ejecuta terraform init.
Módulos sin versión fija
Fija siempre version (Registry) o ?ref= (Git) para evitar sorpresas.
