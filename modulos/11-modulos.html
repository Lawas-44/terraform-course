Lección

Qué es un módulo

Un módulo es una carpeta con archivos .tf que puedes reutilizar. Es como una receta: la escribes una vez y la usas todas las veces que quieras con ingredientes distintos.

  • La carpeta donde ejecutas Terraform se llama módulo raíz (root module).
  • Las carpetas que llamas desde ella son módulos hijos (child modules).
Parte del móduloPara qué sirve
variableLos datos que recibe
resourceLo que crea
outputLos datos que devuelve

Consejos para crear buenos módulos

  • Que hagan una sola cosa clara (una red, una web, una base de datos).
  • Variables con description y type.
  • Outputs con todo lo que otros puedan necesitar.
  • No pongas bloques provider dentro del módulo: deja que los reciba del módulo raíz.
  • Añade un README.md explicando cómo usarlo.

Práctica guiada

Módulo de web estática

  1. Crea modules/static-site con un bucket S3 configurado como web.
  2. Expón el nombre del bucket y la URL como outputs.
  3. Instáncialo dos veces (dev y prod) con for_each.
  4. Sustituye tu VPC manual por el módulo oficial del Registry.
  5. Genera el README del módulo con terraform-docs markdown table.
ImportanteSi has creado recursos en la nube, ejecuta terraform destroy al terminar para no pagar por ellos.

Has añadido un módulo nuevo: ejecuta terraform init.
Módulos sin versión fija
Fija siempre version (Registry) o ?ref= (Git) para evitar sorpresas.

Toda configuración tiene un root module; los demás son child modules.

Sintaxis: module.NOMBRE.OUTPUT.

Los módulos encapsulan sus recursos; la interfaz son las variables y los outputs.

init descarga o registra los módulos.

// separa el repositorio de la ruta del módulo; ref es la versión.
