Módulo 15

Proyecto final y certificación

Integrar todo en una infraestructura completa y preparar la certificación oficial.

Avanzado⏱ 4–6 h
En esta página ObjetivosContenidoEjemploPrácticaComandosErrores frecuentesAutoevaluación

🎯 Objetivos de aprendizaje

Al terminar este módulo serás capaz de:

  • Diseñar y desplegar una infraestructura de varios componentes con buenas prácticas.
  • Documentar el proyecto como lo haría un equipo profesional.
  • Conocer el temario de la certificación HashiCorp Certified: Terraform Associate.

📚 Contenido

  1. Arquitectura propuesta: VPC con subredes públicas/privadas, Application Load Balancer, Auto Scaling Group con EC2, bucket S3 para estáticos, (opcional) RDS.
  2. Requisitos: módulos propios + Registry, backend remoto, dos entornos, variables validadas, tests, CI con plan en PR.
  3. Entregables: código, README con diagrama, outputs útiles, evidencia de destroy.
  4. Rúbrica de evaluación: funcionalidad, organización, seguridad, documentación, coste.
  5. Certificación Terraform Associate: dominios del examen, formato, simulacros y recursos oficiales (consulta la versión vigente del examen en la web de HashiCorp).
  6. Siguientes pasos: Kubernetes con Terraform, Terragrunt, OpenTofu, otras nubes, CDK for Terraform.
✍️ Lección en desarrollo. Este es el guion del módulo. Ve sustituyendo este aviso por la explicación completa de cada punto.

🧩 Ejemplo

🛠 Práctica guiada: Web escalable en AWS

  1. Dibuja el diagrama de arquitectura antes de escribir código.
  2. Implementa los módulos network, web y static-site.
  3. Despliega dev desde CI y comprueba la URL del balanceador.
  4. Ejecuta infracost y documenta el coste estimado.
  5. Destruye todo y deja constancia en el README.
💸 Recuerda: si has creado recursos en la nube, ejecuta terraform destroy al terminar.

⌨️ Comandos clave

ComandoQué haceCopiar
terraform plan -var-file=prod.tfvars -out=prod.tfplanPlan de producción guardado.
terraform destroy -var-file=dev.tfvarsLimpieza final del entorno.

Olvidar destruir el NAT Gateway o el ALB
Son de los recursos que más cobran por hora. Revisa la factura al día siguiente.
