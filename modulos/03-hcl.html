Temario / Módulo 03

El lenguaje HCL

Sintaxis, bloques, tipos de datos, referencias y convenciones de estilo.

Nivel: BásicoDuración: 1,5 hTest: 6 preguntasRetos: 2Proyecto: paso 4

Objetivos

Al terminar este módulo sabrás:

  • Reconocer la anatomía de un bloque: tipo, etiquetas y cuerpo.
  • Conocer los tipos de datos: string, number, bool, list, set, map, object, tuple.
  • Usar interpolación, heredocs y referencias entre recursos.
  • Aplicar terraform fmt y terraform validate.

Lección

Los bloques

El lenguaje de Terraform se llama HCL. Todo se escribe en bloques. Un bloque tiene un tipo, unas etiquetas entre comillas y un contenido entre llaves { }:

Los bloques que más vas a usar:

BloquePara qué sirve
resourceAlgo que Terraform crea
dataAlgo que ya existe y Terraform solo consulta
variableUn dato de entrada que se puede cambiar
outputUn dato que se muestra al terminar
localsValores de ayuda para no repetir
providerConfigura un provider (por ejemplo, la región de AWS)
terraformAjustes de Terraform (versiones y providers)

Un recurso puede usar datos de otro. Se escribe TIPO.NOMBRE.DATO:

Aquí local_file.env usa el número que ha generado random_integer.puerto. Terraform entiende que primero tiene que crear el número.

Ordenar y comprobar el código

Dos comandos te ayudan a tener el código limpio y sin errores:

  • terraform fmt ordena el código (sangría y alineación).
  • terraform validate busca errores sin crear nada.
  • terraform fmt -check no cambia nada: solo avisa si hay archivos sin ordenar. Se usa en revisiones automáticas.

Práctica guiada

Explora tipos con la consola

  1. Pega los locals del ejemplo en un proyecto vacío.
  2. Abre terraform console y evalúa local.lista[1], local.mapa["equipo"], local.mensaje.
  3. Desordena la indentación a propósito y ejecuta terraform fmt -diff.
  4. Introduce un error de sintaxis y lee el mensaje de terraform validate.

Comandos clave

ComandoQué haceCopiar
terraform fmtFormatea los .tf del directorio actual.
terraform fmt -recursive -diffFormatea subcarpetas y muestra los cambios.
terraform fmt -checkFalla si algo no está formateado (útil en CI).
terraform validateValida sintaxis y coherencia interna.
terraform consoleConsola interactiva para probar expresiones.

Errores frecuentes

Error: Unsupported argument
Argumento mal escrito o que no existe en ese recurso. Revisa la documentación del provider.
Usar comillas simples 'texto'
HCL solo acepta comillas dobles.

Elige una respuesta en cada pregunta. Verás la explicación al momento. Con un 80 % o más, el módulo está superado.

01¿Cuántas etiquetas lleva un bloque resource?

Por ejemplo resource "local_file" "saludo".

02¿Cuál es una forma válida de escribir un string en HCL?

HCL solo admite comillas dobles.

03¿Qué diferencia a un set de una list?

Un set elimina duplicados y no garantiza orden; por eso no se accede por índice.

04¿Cómo se referencia el atributo result del recurso random_integer.puerto?

La sintaxis es TIPO.NOMBRE.ATRIBUTO. La interpolación ${} solo es necesaria dentro de strings.

05Tienes main.tf y zzz.tf en la misma carpeta. ¿En qué orden los procesa Terraform?

Terraform construye un único grafo con todos los archivos .tf de la carpeta.

06¿Qué hace terraform fmt -check?

Muy útil en CI para exigir código formateado.
