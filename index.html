Aprende Terraform y Ansible desde cero

Aprende a crear servidores en la nube con Terraform y a configurarlos con Ansible. Mientras aprendes, construyes paso a paso un proyecto real: tu propia web funcionando en AWS.

Empezar el cursoChuleta de comandos
  • 23módulos
  • 22pasos del proyecto guiado
  • ~50 hde contenido y prácticas
  • 0 €para empezar (capa gratuita de AWS)

Lo que tendrás al terminar

Una web personal funcionando en dos servidores de AWS. Terraform crea la red, el firewall y los servidores; Ansible instala nginx, publica tu web, añade una página de estado y una zona privada con contraseña. Todo se crea con un solo comando y se borra con otro.

Terraform

Red propia (VPC), firewall, clave SSH y dos servidores Ubuntu. Estado guardado en S3.

Ansible

Roles para preparar el sistema, instalar nginx y publicar tu web con plantillas.

Integración

Terraform genera el inventario de Ansible y un script lo despliega todo.

Calidad

Tests, ansible-lint y GitHub Actions revisando cada cambio.

Ver el proyecto paso a paso

Cómo funciona el curso

Para quién

Para cualquier persona que empiece de cero. No hace falta saber programar ni haber usado la nube.

Qué necesitas

Un ordenador con Windows (con WSL), macOS o Linux. A partir del módulo 5, una cuenta de AWS.

Cómo se aprende

Cada módulo tiene: objetivos, lección, un paso del proyecto, práctica guiada, comandos, errores frecuentes, test y retos.

Sin gastar dinero

Usamos servidores de la capa gratuita de AWS y al terminar cada sesión los borramos con terraform destroy.

Antes de empezar

  • Sé abrir una terminal y moverme entre carpetas (repaso aquí).
  • Tengo Git instalado y una cuenta de GitHub.
  • Tengo un editor de código (recomendado: VS Code).
  • Sé que nunca se suben contraseñas ni archivos .tfstate a GitHub.
  • A partir del módulo 5: cuenta de AWS con alertas de gasto.
  • Reservo 2 a 4 horas por semana.
