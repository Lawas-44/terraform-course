Cómo está pensado el curso

👤 Para quién

Personas sin experiencia en Terraform ni en la nube: estudiantes, desarrolladores, sysadmins o perfiles de soporte que quieren dar el salto a DevOps/Cloud.

🧰 Qué necesitas

Un ordenador (Windows, macOS o Linux), ganas de usar la terminal y, a partir del módulo 5, una cuenta de AWS con alertas de presupuesto. No hace falta saber programar.

🔁 Cómo se aprende

Cada módulo sigue el mismo patrón: objetivos → teoría breve → ejemplo → práctica guiada → comandos → errores frecuentes → autoevaluación.

💸 Sin sustos en la factura

Empezamos con providers locales (local, random), luego usamos recursos de la capa gratuita y cada práctica termina con terraform destroy.

🔀 Terraform u OpenTofu

Usamos Terraform (1.10 o superior). Casi todo lo aprendido funciona igual en OpenTofu cambiando terraform por tofu.

🎓 Hacia la certificación

El temario cubre los dominios del examen HashiCorp Certified: Terraform Associate y termina con un proyecto para tu portfolio.

Checklist antes de empezar

  • Sé abrir una terminal y moverme entre carpetas (repaso aquí).
  • Tengo Git instalado y una cuenta de GitHub.
  • Tengo un editor (recomendado: VS Code + extensión HashiCorp Terraform).
  • Sé que nunca se suben claves ni archivos .tfstate a GitHub.
  • (Módulo 5+) Cuenta de AWS con MFA, usuario no-root y presupuesto con alertas.
  • Reservo 2–4 horas por semana: el curso completo cabe en 2–3 meses.
