Curso gratuito · En español · Desde cero

Aprende Terraform desde cero

Aprende a crear infraestructura con código, paso a paso. Cada módulo tiene una explicación sencilla, ejemplos que puedes copiar, un test y ejercicios.

Empezar el cursoChuleta de comandos

  • ~35 hde contenido y prácticas
  • 0 €para empezar (módulos 0 a 4 sin nube)

Cómo funciona el curso

Para quién

Para cualquier persona que empiece de cero. No hace falta saber programar ni haber usado la nube.

Qué necesitas

Un ordenador con Windows, macOS o Linux. A partir del módulo 5, una cuenta de AWS.

Cómo se aprende

Cada módulo tiene: objetivos, lección, práctica guiada, comandos, errores frecuentes, test y retos.

Sin gastar dinero

Empezamos sin nube. Después usamos recursos gratuitos y cada práctica termina con terraform destroy.

Antes de empezar

  • Sé abrir una terminal y moverme entre carpetas (repaso aquí).
  • Tengo Git instalado y una cuenta de GitHub.
  • Tengo un editor de código (recomendado: VS Code).
  • Sé que nunca se suben contraseñas ni archivos .tfstate a GitHub.
  • A partir del módulo 5: cuenta de AWS con alertas de gasto.
  • Reservo 2 a 4 horas por semana.
