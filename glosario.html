Referencia

Glosario

Las palabras del curso, explicadas en una línea.

Apply
Ejecutar los cambios del plan contra la infraestructura real.
Backend
Lugar donde se guarda el estado (local, S3, HCP Terraform…).
Bloque
Unidad básica de HCL: tipo + etiquetas + cuerpo entre llaves.
Child module
Módulo llamado desde otro módulo mediante un bloque module.
ClickOps
Gestionar infraestructura a mano desde consolas web.
count
Meta-argumento que crea N copias de un recurso indexadas por número.
Data source
Bloque data que lee información existente sin crearla.
Declarativo
Describir el estado final deseado en lugar de los pasos.
Drift
Diferencia entre el estado y la realidad por cambios hechos fuera de Terraform.
Dynamic block
Genera bloques anidados repetidos a partir de una colección.
for_each
Meta-argumento que crea instancias indexadas por clave de un map o set.
HCL
HashiCorp Configuration Language, el lenguaje de Terraform.
HCP Terraform
Servicio SaaS de HashiCorp (antes Terraform Cloud) para estado y ejecuciones remotas.
IaC
Infraestructura como Código.
Idempotencia
Aplicar lo mismo varias veces produce el mismo resultado.
Import
Poner bajo gestión de Terraform un recurso que ya existe.
Lifecycle
Bloque que ajusta cómo se crean, actualizan o destruyen los recursos.
Local value
Valor con nombre calculado dentro de un módulo (local.x).
Lock file
.terraform.lock.hcl: fija versiones y hashes de providers.
Meta-argumento
Argumento válido en cualquier recurso: count, for_each, depends_on, provider, lifecycle.
Módulo
Conjunto de archivos .tf en una carpeta, reutilizable con entradas y salidas.
OpenTofu
Fork open source de Terraform mantenido por la Linux Foundation.
Output
Valor que expone un módulo hacia fuera o hacia la terminal.
Plan
Propuesta de cambios calculada comparando código, estado y realidad.
Provider
Plugin que permite a Terraform hablar con una API (AWS, Azure, GitHub…).
Recurso
Bloque resource: un objeto de infraestructura gestionado.
Registry
registry.terraform.io: catálogo público de providers y módulos.
Root module
La carpeta donde ejecutas los comandos de Terraform.
Sensitive
Marca que oculta un valor en la salida (no lo cifra en el estado).
State
Archivo que mapea tu código con los recursos reales.
State lock
Bloqueo que impide dos operaciones simultáneas sobre el mismo estado.
Taint
Marcar un recurso para recrearlo; hoy se usa apply -replace.
tfvars
Archivo con valores de variables.
Variable
Parámetro de entrada de un módulo (var.x).
Workspace
Estado independiente que comparte la misma configuración.
