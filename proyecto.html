Tu web en la nube

A lo largo del curso construyes, paso a paso, una web personal que funciona de verdad en AWS. Cada módulo añade una pieza. Al final, un solo comando crea los servidores y los deja configurados.

El resultado

  • Dos servidores Ubuntu en AWS, dentro de tu propia red y protegidos por un firewall.
  • Tu web personal (nombre, descripción y proyectos) servida por nginx en los dos servidores.
  • Una página /estado.html que muestra los datos de cada servidor.
  • Una zona /privado/ protegida con usuario y contraseña cifrada con Ansible Vault.
  • Despliegue con ./scripts/desplegar.sh y borrado con ./scripts/destruir.sh.
  • Tests y revisiones automáticas en GitHub Actions.

Cómo encaja todo

Terraform crea todo lo que hay en AWS y escribe el inventario de Ansible con las IPs de los servidores. Ansible entra por SSH en cada servidor y lo configura.

Estructura final del repositorio

El código terminado está en la carpeta proyecto/ del repositorio del curso. Úsalo para comparar si te atascas.

Cuánto cuesta

Los servidores t3.micro y el resto de recursos entran en la capa gratuita de AWS para cuentas nuevas. Fuera de ella, los dos servidores cuestan unos céntimos por hora. Borra todo con terraform destroy al terminar cada sesión y vuelve a crearlo la siguiente: es justo la ventaja de tenerlo en código.

Curso abierto de Terraform para principiantes. Código en GitHub. Terraform es una marca de HashiCorp; este curso no está afiliado.
