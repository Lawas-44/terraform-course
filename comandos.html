Flujo de trabajo básico

Los comandos que usarás el 90 % del tiempo.

ComandoQué haceCopiar
terraform initInicializa el directorio: backend, providers y módulos.
terraform init -upgradeActualiza providers y módulos a la última versión permitida.
terraform validateComprueba sintaxis y coherencia.
terraform fmt -recursiveFormatea todos los .tf (incluidas subcarpetas).
terraform planPrevisualiza los cambios.
terraform plan -out=tfplanGuarda el plan para aplicarlo después.
terraform applyAplica los cambios tras confirmación.
terraform apply tfplanAplica un plan guardado (sin preguntar).
terraform apply -auto-approveAplica sin confirmación (solo en automatización).
terraform destroyDestruye todos los recursos de la configuración.
terraform plan -destroyPrevisualiza qué destruiría destroy.

Variables y opciones de plan/apply

Flags que acepta plan, apply y destroy.

ComandoQué haceCopiar
terraform plan -var="entorno=dev"Asigna una variable.
terraform plan -var-file="dev.tfvars"Carga un archivo de variables.
terraform apply -replace="aws_instance.web"Fuerza la recreación de un recurso.
terraform plan -target="module.vpc"Limita el plan a un recurso/módulo (solo emergencias).
terraform plan -refresh=falseNo consulta la nube (más rápido, menos preciso).
terraform plan -refresh-onlySolo detecta drift.
terraform plan -detailed-exitcodeCódigo de salida 2 si hay cambios (scripts/CI).
terraform apply -parallelism=20Operaciones simultáneas (por defecto 10).
terraform apply -lock-timeout=5mEspera al bloqueo del estado en vez de fallar.
terraform plan -input=false -no-colorModo no interactivo y sin colores (CI).
terraform -chdir=envs/dev planEjecuta en otra carpeta.

Añádelos a ~/.bashrc, ~/.zshrc o a tu perfil de PowerShell.

Errores comunes y cómo salir de ellos

MensajeSolución
Error: Inconsistent dependency lock fileterraform init -upgrade
Error: Backend initialization requiredterraform init (o -reconfigure / -migrate-state)
Error acquiring the state lockEsperar; si el proceso murió: terraform force-unlock LOCK_ID
Error: No valid credential sources foundRevisar AWS_PROFILE y aws sts get-caller-identity
Error: Reference to undeclared resourceNombre mal escrito o recurso en otro módulo (usa outputs).
Error: Invalid for_each argumentLas claves deben conocerse en el plan; evita atributos calculados.
Error: CycleDos recursos se referencian mutuamente; separa en recursos de regla/asociación.
Error: Provider produced inconsistent resultBug o eventual consistency del provider: reintentar y actualizar versión.
Module not installedterraform init
